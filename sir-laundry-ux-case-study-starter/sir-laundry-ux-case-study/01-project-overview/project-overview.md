# Sir Laundry — Project Overview

## 1. Project Introduction

Sir Laundry is a campus laundry management app designed to make laundry services easier and more predictable for university students. The project focuses on helping students access important laundry information before visiting the laundry facility.

## 2. Problem Statement

Students may be unsure whether the campus laundry is open, what its operating timings are, the current status of the service, and how much their laundry might cost. This uncertainty can lead to unnecessary trips, wasted time, and inconvenience.

## 3. Project Goal

The goal of Sir Laundry is to reduce uncertainty and help students make informed decisions about using campus laundry services.

The central questions the app aims to answer are:

- Can I go to the laundry?
- When can I go?
- What is happening with the laundry service?
- How much will my laundry cost?

## 4. Core Features

1. **Laundry Availability:** Check whether the laundry service is available.
2. **Operating Timings:** Find the laundry's operating hours.
3. **Laundry Status:** Check the current status of the service.
4. **Estimated Laundry Cost:** Estimate the cost before submitting laundry.

## 5. Design Approach

The project follows a user-centred design approach, including user research, information architecture, prioritisation, wireframing, prototyping, usability testing, and design iteration.

## 6. Expected Outcome

The intended outcome is a clear, compact, and easy-to-use experience that helps students understand laundry availability, timings, status, and estimated costs before making decisions.

## 7. Project Scope

Sir Laundry is an HCI end-term design project. This repository documents the design process, research findings, design decisions, prototype, and usability testing.

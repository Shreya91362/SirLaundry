# 01 — Project Overview

This section introduces Sir Laundry, a campus laundry management app designed to reduce uncertainty for students using the university laundry service.

## Included Documents

- **[Project Brief](PROJECT_BRIEF.md):** The problem, project goals, target users, and scope.
- **[Project Overview](project-overview.md):** The introduction, core features, design approach, and intended outcome.

## Project Focus

Sir Laundry aims to help students answer four key questions:

- Can I go to the laundry?
- When can I go?
- What is happening with the laundry service?
- How much will my laundry cost?

This repository documents the HCI design process, from research and information architecture to prototyping and usability testing.

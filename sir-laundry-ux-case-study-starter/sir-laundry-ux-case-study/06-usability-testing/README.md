# Prototype Usability Testing

## Participants and feedback
Five students provided the following suggestions.

| Participant | Feedback | Design response |
|---|---|---|
| Asmi | Multiple wash-type choices | Added Regular, Delicate and Heavy options |
| Adavay | Multiple wash-type choices | Added separate wash quantities |
| Kunj | Keep bottom navigation visible | Fixed bottom navigation on secondary screens |
| Neermay | Light and dark modes | Added Light and Night modes |
| Leo | More compact design | Reduced unnecessary spacing |

## Evidence and limitations
These are participant suggestions. Do not claim task-failure rates or success percentages unless they were measured and recorded.

## Next step
Retest the revised prototype to check whether the changes reduce friction.
